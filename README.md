# Shaadi Sangeet

A Next.js shaadi-themed music landing page with a glassmorphism player, rotating album art, live Indian time, and a live online badge.

## Run locally

```bash
npm install
npm run dev
```

## Notes

- The playlist uses public demo audio sources so the player works immediately.
- Swap the `src` values in `app/page.tsx` if you want to point it at your own wedding playlist.
